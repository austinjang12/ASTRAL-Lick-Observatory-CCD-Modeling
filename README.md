# ASTRAL-Lick-Observatory-CCD-Modeling
# Synthetic CCD Noise Simulation

This project investigates how controlled synthetic CCD noise affects astronomical image data. The goal is to build a physically motivated noise model and study how different sources of detector noise alter an underlying astronomical signal.

The simulation begins with an astronomical image and applies several sources of synthetic detector noise:

- **Poisson shot noise** — models the statistical fluctuations associated with photon/electron counting.
- **Dark current noise** — models additional electrons generated by the detector during an exposure.
- **Gaussian read noise** — models uncertainty introduced during the electronic readout of the detector.
- **Saturation** — models the finite full-well capacity of a CCD by limiting the maximum recorded signal.

The resulting image can then be compared directly with the original image to quantify how the signal changes as noise is introduced.

## Noise Model

The simulated observed pixel value can be represented schematically as

\[
O = S + N_{\mathrm{shot}} + N_{\mathrm{dark}} + N_{\mathrm{read}},
\]

where \(S\) is the underlying signal and the remaining terms represent different detector-noise contributions.

### Shot Noise

Photon-counting fluctuations are modeled using a Poisson distribution:

\[
O_{\mathrm{shot}} \sim \mathrm{Poisson}(S).
\]

The variance of a Poisson-distributed signal is equal to its mean,

\[
\mathrm{Var}(N_{\mathrm{shot}})=S.
\]

Consequently, the standard deviation scales as

\[
\sigma_{\mathrm{shot}}=\sqrt{S}.
\]

This means that brighter pixels have larger absolute fluctuations, while the relative noise decreases as the signal increases.

### Dark Current

Dark current is simulated as an additional Poisson-distributed contribution:

\[
N_{\mathrm{dark}}\sim\mathrm{Poisson}(\lambda_{\mathrm{dark}}),
\]

where \(\lambda_{\mathrm{dark}}\) represents the expected number of dark-current electrons per pixel for the simulated exposure.

### Read Noise

Electronic readout noise is modeled as Gaussian noise:

\[
N_{\mathrm{read}}\sim\mathcal{N}(0,\sigma_r^2),
\]

where \(\sigma_r\) is the assumed read-noise standard deviation.

Unlike Poisson noise, the Gaussian read-noise contribution is independent of the brightness of the pixel in this simplified model.

### Saturation

A finite detector well depth is included by imposing a maximum measurable signal:

\[
O_{\mathrm{final}}=
\min(O,O_{\mathrm{FW}}),
\]

where \(O_{\mathrm{FW}}\) is the detector's full-well capacity.

This prevents simulated pixels from exceeding the maximum signal that the detector can record.

## Simulation Pipeline

The experiment follows the general pipeline:

```text
Input Astronomical Image
          ↓
    Add Dark Current
          ↓
    Apply Shot Noise
          ↓
     Add Read Noise
          ↓
       Saturation
          ↓
    Simulated CCD Image
```

The original image is preserved so that the effect of each noise source can be examined quantitatively.

## Controlled Noise Experiments

One purpose of using synthetic noise is that its parameters are known and controllable. Unlike the unknown noise already present in a real astronomical observation, the simulated noise can be systematically varied.

For example, the simulation can be repeated for different values of:

\[
\sigma_r,\qquad
\lambda_{\mathrm{dark}},\qquad
O_{\mathrm{FW}},
\]

allowing the effect of increasing detector noise to be measured.

This makes it possible to investigate questions such as:

- How does increasing read noise affect the recovered signal?
- At what noise level does the astronomical signal become difficult to distinguish from fluctuations?
- How does shot noise scale with signal intensity?
- How does detector saturation affect bright sources?
- Which noise component dominates under different signal conditions?

## Example Implementation

A simplified implementation is:

```python
# Dark current
dark_current = 5
image += np.random.poisson(dark_current, image.shape)

# Shot noise
image = np.random.poisson(np.clip(image, 0, None))

# Read noise
read_sigma = 20
image += np.random.normal(0, read_sigma, image.shape)

# Detector saturation
full_well = 60000
image = np.clip(image, 0, full_well)
```

The parameters can be changed to perform different noise experiments.

## Why Synthetic Noise?

Synthetic noise provides a controlled environment for studying detector effects.

A real astronomical image contains noise from many sources, and the exact realization of that noise is generally unknown. By introducing additional noise with explicitly specified statistical properties, the experiment can isolate individual effects and measure how the image responds to controlled changes in the noise model.

The synthetic noise therefore acts as an experimental parameter rather than an attempt to claim that the original astronomical observation was acquired with the exact simulated detector characteristics.

## Future Extensions

Possible extensions include:

- Comparing simulated noise distributions with measured CCD noise.
- Separately measuring the contribution of each noise source.
- Performing signal-to-noise ratio measurements.
- Testing different read-noise and dark-current regimes.
- Modeling gain and conversion between electrons and ADU.
- Including spatially varying dark current.
- Comparing the Gaussian read-noise approximation with more detailed detector models.
- Studying how noise propagates through subsequent image-processing and source-recovery algorithms.
